Why this timing?
  • ▸ x402 already processed 160M+ agent payments (avg ~$0.26).
  • ▸ IDC: active agents grow from ~29M (2025) → 2.2 billion by 2030.
  • ▸ Agent task volume explodes (524% CAGR). Most tasks can trigger micro-payments.
  • ▸ Payment rails (x402, AP2, MPP, agent wallets, stablecoins) are already live.
Main constraints
  • ▸ Current agent payments are still mostly micro. Value flip needs larger average transaction sizes.
  • ▸ Human payment base is enormous. Agents need real economic authority, not just wallets.
  • ▸ Identity, liability & regulation for autonomous agents are still immature.

Transaction count flips first because machines love micro-payments. Meaningful value volume takes longer.
